# PDF Workspace Website

Статический сайт проекта для GitHub Pages.

- index.html — структура и контент.
- styles.css — адаптивный дизайн, светлая и тёмная темы.
- app.js — RU / EN / ES, переключение темы и интерактивный макет Monic Control Bar.
- assets/ — иконка, обложка и стикеры.

Локальный просмотр: откройте index.html в браузере или запустите любой static server из папки web.

Сайт не использует сборщик, серверную часть, аналитику или сторонние JS-библиотеки. Все изображения интерфейса — концептуальные иллюстрации, а не скриншоты готового приложения.

GitHub Pages: workflow публикует содержимое папки web. В настройках репозитория выберите Settings → Pages → GitHub Actions.
